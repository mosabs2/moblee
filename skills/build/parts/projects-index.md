# Projects

Everything built beside this wiki for its owner, one short section per thing. Each has its own page in `wiki/Projects/` with the decisions, the progress and how to go back; this page is the index and says only what each thing is, where it lives, how to open it and where it stands. The code lives in `apps/<name>/` in the wiki folder, or outside it at `~/Apps/<name>/` for anything that needs installing, with a pointer in `apps/`.
